>

> 
> 📱 **System Integration** - Seamlessly integrated with HarmonyOS sharing system for effortless user experience
> 
> 🎯 **Smart Recognition** - Automatically identifies Huawei AppGallery links and precisely extracts package name information

## 📖 User Guide

### 🚀 Quick Start

<details>
<summary><strong>Method 1: Use via System Sharing (Recommended)</strong></summary>

1. **🛒 Open Huawei AppGallery**
   - Browse or search for the app you need the bundle name for

2. **📤 Click Share Button**  
   - Click the share icon on the app details page
   - Select "AppBundleNameForShared" application

3. **⚡ Auto Extract Package Name**
   - The app will automatically parse the link and display the package name
   - Supports real-time status feedback

4. **📋 One-Click Copy & Use**
   - Click the copy button to copy package name to clipboard
   - Paste directly into other applications

</details>

<details>
<summary><strong>Method 2: Direct App Launch</strong></summary>

Directly launching the app displays a detailed user guide interface, including:
- 📝 Complete step-by-step instructions

</details>
